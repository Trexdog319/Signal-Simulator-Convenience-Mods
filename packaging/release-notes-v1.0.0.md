## ⬇️ Download

Under **Assets** below, download **`SignalSimulatorMods-FullInstall.zip`**.
(You don't need the "Source code" files. GitHub adds those automatically.)

## Install

1. In Steam, right-click **Signal Simulator → Manage → Browse local files**.
2. Extract everything from the zip into that folder (`winhttp.dll` should sit next to `SignalSimulator.exe`).
3. Start the game. The new settings are under **Options → Gameplay**.

**To uninstall**, delete `winhttp.dll`, `doorstop_config.ini`, `.doorstop_version` and the `BepInEx` folder.
Your game files are never changed.

## What's included

**Movement**
- **Jump** with Space. Hold it to bunny hop and keep your speed.
- **Crouch** with Left Ctrl or C.
- Steer while in the air, including diagonally.
- Camera sway: a gentle walk sway and a lean when strafing. You can turn it off.
- Golf kart: smoother acceleration and steering, and it doesn't lose all its speed on bumps. You can turn it
  off.

**Radio signals**
- **Random Event Signals**: secret event signals can show up at random, instead of only on specific
  real-world dates and times. You can turn this off to get the original schedule back.
- **Radio Event Chance** (default 3%) and **Radio Story Chance** (default 10%) sliders.

Includes [BepInEx 5.4.23.2](https://github.com/BepInEx/BepInEx), the mod loader these mods run on.
